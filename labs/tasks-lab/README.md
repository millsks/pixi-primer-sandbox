# tasks-lab

Lab for [Pixi Tasks](../../docs/pixi-tasks.md).

```sh
cp -r labs/tasks-lab sandbox/ && cd sandbox/tasks-lab
pixi init .
```

Files:

- `scripts/where.py` — prints its working directory and `MODE`; used by the `cwd` / `env` step
- `in.txt` — input for the `inputs` / `outputs` caching step
